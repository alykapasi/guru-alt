# Jev capability research snapshot

Date: 2026-09-18. Status: proposed research, not an approved integration or production assessment. Sources: public official TypeSafe documentation and read-only inspection of the installed `typesafe-sdk` 0.6.0 package. No SDK was executed, authenticated request made, benchmark run, or credential read. Public documentation and account entitlements can change.

## Product and compatibility

Jev is TypeSafe AI's System One decision model. It evaluates text or structured application state against predefined questions and returns typed decisions and distributions. It does not generate tutor dialogue, lessons, explanations, code, or reasoning narratives. Questions in one request independently evaluate the same state; this is not an ordered conversation or a chain in which later questions see earlier answers. Text-only input means Guru must perform OCR/transcription elsewhere. These are documented interface facts; the quality of its judgments on Guru data is unmeasured. [System One](https://docs.typesafe.ai/concepts/system-one), [State](https://docs.typesafe.ai/concepts/state).

**Architecture inference:** put a provider-neutral decision capability behind `app/llm/` to preserve Guru's SDK boundary, with a separate request/result contract and decision-role configuration. Do not force Jev into the generic generative, streaming, embedding, or tool-call interface. Services can request a decision through this seam; deterministic Guru policy remains responsible for applying it. Placement inside `app/llm/` does not mean registering it as a generative provider. Any parallel orchestration, retries, batching across states, or persistence belongs to Guru rather than assumed vendor jobs.

## Claims versus evidence

The launch blog advertises 70–500ms end-to-end response time, $42 per billion input tokens, large speed/cost advantages, calibration, and no hallucinations. These are vendor claims, not Guru measurements. The blog qualifies its evaluation geography as West Coast laptops near the service, uses reference probabilities from frontier models rather than ordinary labeled ground truth, notes possible capabilities-team selection bias, and describes its zero-hallucination figure as a schema guarantee rather than empirical semantic accuracy. Consequently typed output does not prove a correct grading or policy decision. [Launch blog](https://typesafe.ai/blog/introducing-system-one-models-and-jev).

Official limitations include unreliable arithmetic/counting/date comparisons, multi-hop indirection, distraction from irrelevant context, adversarial state, conflicting instructions, and absent guarantees of probability identities across separately phrased questions. Keep arithmetic, FSRS scheduling, tracer updates, authorization, and policy invariants in Guru code; treat Jev as fallible semantic evidence. This is vendor disclosure, not a measured failure rate for Guru. [Jev 1.13 jaggedness](https://docs.typesafe.ai/model-jaggedness/jev-1.13).

Choice/Score confidence summarizes distribution shape; its exact formula is not established by the reviewed confidence page. Probability and confidence should not be equated with an individually guaranteed correctness rate. Thresholds need labeled, held-out Guru evaluation and version-specific tuning. [Confidence](https://docs.typesafe.ai/confidence).

## Data handling and unresolved questions

The privacy policy promises not to train/fine-tune on customer Input, restricts Input sharing to service providers, says hosting is in the US, describes deletion/de-identification on request subject to necessity/legal retention, and excludes under-18 services. It does not establish a fixed standard retention period or an API deletion method. [Privacy policy](https://typesafe.ai/legal/privacy-policy).

The DPA defines controller/processor roles, documented-instruction processing, subprocessor arrangements, and retention tied to processing need and applicable laws; no concrete standard purge interval is established. [DPA](https://typesafe.ai/legal/data-processing). Zero-data-retention is separately advertised for enterprise customers and must not be assumed enabled for Guru. [Legal](https://docs.typesafe.ai/legal).

Before any real learner-data pilot, resolve applicable agreement/plan, retention and backup purge, deletion mechanism and timeline, ZDR eligibility/configuration, subprocessor locations, request/response logging, and actual account limits. This snapshot makes no legal compliance determination. Default SDK DEBUG wire logging includes request/response bodies even though sensitive headers are filtered (`_core/transport.py:60`); production observability must avoid raw learner state.

## SDK/documentation drift to handle explicitly

- API reference calls question instructions required, while installed question structs permit omitted/null instructions. Always provide explicit instructions in Guru's stricter boundary.
- Installed score validation rejects empty criteria but does not enforce the public 2–10 level constraint. Enforce documented limits independently.
- Public response decoding skips unknown answer types for forward compatibility (`_core/response_types.py:145`); a successful decode can therefore omit an expected answer. Reject incomplete or mismatched results before applying decisions.
- Generated wire usage and public usage disagree on billing units. Use public types and treat missing token counts as unknown, never zero.

## Recommended evaluation scope

Start with one reversible, bounded decision such as semantic relevance or intent triage, against the existing generative-model baseline in shadow mode. Independently labeled examples should cover abstention, insufficient evidence, adversarial material, long context, and non-English input. Measure task agreement/error by action, confidence reliability, abstention coverage, actual regional p50/p95/p99 latency including queue/retries, throughput, and invoiced cost. Keep learner-visible grading, mastery updates, and profile/memory persistence gated until evidence establishes their suitability. No benchmark results or rollout approval are implied by this document.
